# NOËL INK · TREE PICK 크리스마스 마을

Node.js와 Three.js를 사용하는 크리스마스 마을 프로토타입입니다.

## 실행하기

Node.js 20 이상이 필요합니다.

```sh
npm install
npm start
```

브라우저에서 `http://localhost:3000/#/village`를 열어 보세요. 테스트는 `npm test`로 실행할 수 있습니다.

이 프로젝트는 로컬 시연용입니다. 편지 데이터는 서버의 `data/` 디렉터리에 저장되며 저장소에 포함되지 않습니다. 공개 운영 전에 HTTPS, 인증, 남용 방지, 백업 및 보안 검토가 필요합니다. Three.js 라이선스는 `public/vendor/THREE-LICENSE.txt`에 포함되어 있습니다.
